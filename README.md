# noomesh.github.io

The landing page for [noomesh.ai](https://noomesh.ai), served via GitHub Pages.

Plain HTML, CSS and JS — no build step. Pushing to `main` publishes, so treat
`main` as production.

`CNAME` binds the custom domain. Do not delete it.

## Local preview

```bash
python -m http.server 4321      # then open http://localhost:4321/
```
