# noomesh.github.io

Landing pages for [noomesh.ai](https://noomesh.ai), served via GitHub Pages.

- `index.html` — root landing page (self-contained, no build step)
- `CNAME` — custom domain binding for GitHub Pages (do not delete)
- DNS is managed in Azure DNS (`noomesh-dns-rg` resource group, `personifai-dns` subscription)

Deploys automatically on push to `main`.
